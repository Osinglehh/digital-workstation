## Layer 1 — 识别与分类

- **工作类型（work type）**：单人办公位组合体（cubicle workstation diorama）。
- **大类**：建筑/家具 + 消费电子 + 桌面陈设的复合静物。
- **primaryDomain**：`object`（非人物）。
- **置信度**：0.93。
- **对象边界**：桌面、三面隔断与顶部书架，以及桌面上可见的笔记本、显示器、键盘、鼠标、杯、瓶、纸笔、电源与线缆；不包含画面外的房间、天花与相邻工位。
- **适配性结论**：**conditional pass**。照片是场景而非单件物体，但用户明确要求整块工作区；四视图可支持主要体积与遮挡关系。背面、桌下内部和书架顶部被裁切，按常见结构与对称性推断；接受程序化风格化近似。拒绝精确品牌文字/制造级尺寸的要求。

## Layer 2 — 整体形与轮廓

- **包围体**：约 1600 mm（宽）× 700 mm（深）× 1900 mm（高，含顶部书架与隔断）。
- **桌面**：矩形厚板，约 1600 × 700 × 25 mm，前缘直边，后缘抵住背板；板下为浅色木纹。
- **隔断**：三面围合。背板下半为木饰面，上部为磨砂玻璃；左右侧板同构；铝型材立柱/压条呈银灰，截面带细凹槽。顶部搁板约 1600 × 300 × 20 mm。
- **对称性**：整体近似左右对称，但陈设高度非对称（左侧笔记本、右侧显示器；右侧挂水壶）。
- **形语言**：家具为严格几何；笔记本为薄楔形+微弧；杯子/水壶为旋转体；鼠标为有机曲面；键帽为倒角方台。
- **比例参照**：以 AOC 27" 显示器宽约 614 mm 作为场景比例锚；桌面宽约 2.6 个显示器宽度；笔记本 16" 宽约 355 mm；键盘 98 键约 390 mm。

## Layer 3 — 宏观 → 中观 → 微观分解

**宏观（macro）**
1. `desk` 桌体（桌面、桌腿/横梁、后挡板）
2. `partition` 隔断系统（背板、左右侧板、铝立柱、磨砂玻璃、压条）
3. `shelf` 顶部搁板与书籍/茶叶罐
4. `laptop` 白色游戏本 + 铝合金支架
5. `monitor` AOC 显示器 + 圆盘底座
6. `keyboard` 98 键机械键盘（渐变灰键帽、RGB、旋钮）
7. `mousepad` + `mouse`
8. `mug` 玻璃茶杯（深色茶汤、木盖、棕色把手）
9. `bottle` UZSPACE 灰绿半透明水壶 + 挂带
10. `deskProps` 笔袋、手写纸、笔记、电源适配器、插排、线缆
11. `leftNeighbor` 左侧邻桌边缘（可选，仅补全环境）
12. `chair` 黑色办公椅（2/3 号图可见，仅部分；低优先级）

**中观（meso）**
- laptop：上盖/屏幕、下壳、键盘面、触控板、屏轴、脚垫、接口、贴纸、支架托臂。
- monitor：前面板、下巴、AOC 标、背壳、立柱、圆盘底座、线缆、电源灯。
- keyboard：上壳、下壳、定位板、98 个键帽、右上旋钮、RGB 灯带/轴灯、脚撑、Type-C 口。
- mug：杯身、茶汤、木盖、盖钮、把手、白纸垫。
- partition：木饰面、磨砂玻璃、铝立柱、玻璃压条、贴纸、挂瓶钩/挂带。
- 桌面陈设：笔袋拉链/提手/布标、手写纸张、黄色封边笔记本、白色电源砖、白插排、黑/白线缆、耳机线。

**微观（micro）**
- 键帽字符（浅灰/白）、键帽倒角高光、轴体透光缝、键盘右上 3 色指示灯、旋钮滚花。
- 桌面木纹（直纹，浅米黄，局部深色纹理）、隔断竖纹、封边条。
- 显示器像素级 UI：蓝色 Windows 11 风格壁纸、任务栏、窗口边框、中文小字。
- 笔记本屏幕：桌面图标网格、终端窗口、任务栏、贴纸。
- 玻璃杯内茶汤液面与反光、木盖年轮、杯壁折射。
- 鼠标垫印刷几何图形与缝线、鼠标脚贴、滚轮、LOGO。
- UZSPACE 纵向白字、瓶盖纹路、挂带织纹。
- 线缆弧度、插头、排插指示灯、桌面灰尘与轻微指纹。

## Layer 6 — 色彩与收尾

- 主色：浅木米黄（低饱和暖色）+ 灰色设备 + 黑色配件；显示器/笔记本屏幕提供高饱和蓝色焦点。
- 键盘键帽为**自上而下由浅到深的灰色渐变**，底部行最深；RGB 背光在缝隙呈蓝紫→青绿→橙色渐变。
- 屏幕为 Windows 11 风格的深蓝底 + 青蓝流线；窗口深灰半透明。
- 木纹方向：桌面横纹、隔断竖纹、书架横纹；色差轻微，局部木节/色带。
- 所有塑料偏哑光；金属只在铝立柱、支架、笔记本边缘出现窄高光。

## Layer 8 — 不确定性与单视图限制

- **被遮挡**：显示器背面、支架后侧、笔记本左右接口、键盘底部脚撑、桌面下方、桌腿结构、线缆路径。
- **被裁切**：书架顶部与书籍上缘、画面左右两侧隔断外延、桌下地面与椅子全貌。
- **模糊/不可辨**：键盘右上徽标（“WEIKAV/…”，不追求精确）、鼠标垫右上品牌字样、水面以下的杯内细节、屏幕小字内容。
- **推断项**：显示器背面为常见 AOC 弧形背壳；桌下为金属框腿；隔断背面与正面同材质；椅子为常规五星脚+网背。
- **处理**：品牌文字只保留可辨识的 AOC / UZSPACE / ROG ZEPHYRUS 与“98 键”结构；其余以小尺寸程序化标记近似。隐藏面按合理结构补全，并在评审中标注置信度。

## 复杂度结论

轮廓 3、部件数量 3、层级深度 3、重复密度 3（98 键、图标网格、书列、线缆）、材质层 3、局部细节 3（木纹/灰尘/指纹/反光）、遮挡风险 3、可动性 3 → **ultra-complex**。目标不是可无限近看的写实扫描，而是**构图、比例、材质与可动结构均正确的工作位数字孪生**。

## 可动画锚点（供规格使用）

- `laptopLid` 屏轴旋转（0–105°）；`laptopScreen` 自发光 UI 纹理。
- `monitorPan` 水平旋转 ±15°、`monitorTilt` 俯仰 ±8°；屏幕 UI 动画。
- 键盘 98 个键帽独立下压 0–2.5 mm；RGB 色相扫描；旋钮旋转。
- 鼠标平面移动/旋转与滚轮旋转。
- 茶杯蒸汽粒子和盖钮开合；水壶绕挂点小幅摆动。
- 台灯式灯光切换（日间/夜间）、键盘灯效开关、屏幕亮灭。
