# 办公位工作区数字孪生（Three.js 程序化场景）

基于 `figure/桌面-4.jpg` 主参考与 `figure/桌面-1/2/3/5/6/7.jpg` 补充视角、`figure/桌底-1/2.jpg` 与 `figure/书包-1/2.jpg` 桌下参考、`figure/桌顶架子-1/2/3.jpg` 架顶参考，并按用户实测桌面尺寸（1050 × 500 mm、16 英寸笔记本、23.8 英寸显示器）重建的可动画工作区场景。场景中的桌面、隔断、桌顶格架（顶板/侧板/背板 + 书籍/礼盒/玻璃罐/茶叶罐/纸品）、桌下承重与配电结构、地面瓷砖、设备、键鼠、茶杯、水壶、纸张、线缆、书包和垃圾桶都由代码生成，参考照片用于材质与造型线索，布局以用户实测为准。

界面收拢为 3D 场景左上角的 SolidWorks FeatureManager 风格**半透明玻璃拟态设计树**（304 px 宽、12 px 背景模糊、13/12.5/12 px 字号层级）：装配体信息、视角、物品、灯光、场景、自动展示和帮助都是树内节点，点击场景设备时检查器作为“物品”下的选中节点展开；瞬时的 Tooltip 与 Toast 仍浮在场景上。选中对象后可控制双屏内容、笔记本开合、键盘灯效、椅子与桌面陈设。**自动展示**节点可一键播放约 45 秒的 7 幕工位演出，并提供真实进度、暂停/继续、下一章节、重播、退出、底部实时功能字幕与录制用的隐藏控件栏；展示完成后会自动恢复开始前的状态。

> 后续开发/自动化代理请先阅读 [AGENTS.md](AGENTS.md)；本文件保留用户可读的尺寸、交互和验证记录。

## 运行

```bash
npm install
npm run dev
```

打开终端提示的地址（默认 `http://127.0.0.1:5173/`）。

生产构建与类型检查：

```bash
npm run typecheck
npm run build
npm run preview
```

## 交互

鼠标拖动旋转、滚轮缩放、点击物体在设计树中打开操作节点；点击空白或按 `Esc` 取消选择。左上设计树常驻，可用标题栏箭头整体折叠，内部节点可同时展开：

- **视角**：主视角、正面、左/右 3/4、俯视、桌下、坐姿视角、键盘近景、显示器近景、笔记本近景、工位全景。切换带缓动；`1–9` 切换前九个常用视角，`R` 或“恢复默认视角”回到主视角。自动环绕在正面 ±68° 弧内缓慢往返，避免相机穿到隔间背墙后。
- **物品**：显示器、笔记本、键盘、鼠标、椅子、茶杯、水壶、书架、书包、垃圾桶。选中后在该对象下方展开检查器，提供“聚焦观察”和各自的操作：双屏亮灭与五种屏幕内容（仪表盘/代码/终端/桌面/专注）、笔记本开合、RGB 五态与四种单色、椅子旋转/后仰、杯盖与蒸汽、水壶摆动、滚轮演示、架上摆件/书包/垃圾桶显隐。桌面整理会收起纸品笔袋、茶杯与水壶；整理开启时相关装饰需先关闭整理再单独切换。
- **灯光**：主灯开关、环境光强度、整体亮度、键盘 RGB 模式（关闭/单色/彩虹/呼吸/柔光）与配色。手动调整会进入“自定义光照”。
- **场景**：白天模式、深夜模式、专注模式、RGB 氛围。每个预设同时调整环境/主光/补光、屏幕内容、键盘灯效与界面明暗主题，不强制切换视角。
- **自动展示**：树内“开始展示”一键播放 7 幕时间线（整体亮相 → 空间环绕 → 桌面细节 → 设备互动 → RGB 灯效 → 氛围切换 → 终章全景），总时长约 45 秒。播放中显示真实章节、时钟、百分比与进度条，底部白色字幕会实时说明当前展示的功能；可暂停/继续、下一章节、重新播放或退出。可开启“展示时隐藏设计树”，开始后整棵树自动隐藏但演示继续；也可随时按 `H` 或点“隐藏控件栏”隐藏，左上角保留一个小型恢复按钮。演示期间普通视角/场景/灯光/物品操作会暂时锁定，避免两套控制争夺相机；播放自然完成后停留约 2 秒，随后自动恢复演示前的相机、场景、RGB、屏幕内容、笔记本开合、桌面整理与显隐，无需手动退出。
- **键盘 RGB**：键帽按参考做成**由后向前逐排变深**的渐变键帽（F 排近白 → 底排近炭黑，字色随深浅切换），在此之上有键缝透光的彩色底光、短距离点光染色与机身两侧/后侧的桌面溢光面；彩虹模式会同时驱动键缝与光池色相，单色/呼吸/柔光按同一套曲线衰减。关闭后底光、点光与溢光全部熄灭。
- 偏好持久化：视角、场景、灯光倍率、RGB、屏幕内容与开关、笔记本合盖、整理模式及装饰显隐会写入 `localStorage`（`workstation-ui-v1`）；刷新后恢复。自动环绕和当前选中物体不持久化；节点展开状态属于会话内的临时状态。
- 窄屏：舞台在 860 px 以下或窗口高度不足 560 px 时改为铺满窗口；设计树宽 370 px 时高度不超过 62vh，节点内容在树内滚动，底部仍保留场景可见，不产生横向溢出。

运行时 API（浏览器控制台或自动化脚本）：

```js
const api = window.__workstation.root.userData.animation;
api.openLaptop(105);
api.closeLaptop();

api.releaseKey(12);
api.setKeyboardRgb('rainbow'); // off / static / rainbow / breathe / soft（'sweep' 兼容为 rainbow）
api.setKeyboardRgbColor('#FFD9A0');
api.setScreenContent('code'); // dashboard / code / terminal / desktop / focus
api.moveMouse(0.02, -0.01);
api.openMugLid(true);
api.toggleSteam(false);
api.swayBottle(3.2);
api.setScreenPower(false);

// 体验层状态与场景预设
window.__workstation.setScene('night');
window.__workstation.setLighting({ master: true, ambient: 1.1, level: 1 });
window.__workstation.getUiState();
window.__workstation.selectObject('keyboard');
window.__workstation.focusObject('shelf');
window.__workstation.toggleAutoOrbit();

// 机位与截图
window.__workstation.setView('front');
window.__workstation.setOrbit(0, 7, 1.55, [0, 1.3, -0.02]);
window.__workstation.capture('front'); // base64 PNG

// 自动展示（45 秒 / 7 幕）
window.__workstation.showcase.start();
window.__workstation.showcase.pause();
window.__workstation.showcase.resume();

window.__workstation.showcase.restart();   // 从第 1 幕重播
window.__workstation.showcase.exit();      // 退出并恢复演示前状态

window.__workstation.showcase.getState();  // 状态/章节/进度/字幕/隐藏态
```

## 自动展示时间线

| # | 章节 | 区间 | 内容 |
|---|---|---|---|
| 01 | 整体亮相 | 0–7 s | 当前机位平滑进入远景，开场标题淡入；日间灯光、仪表盘屏幕 |
| 02 | 空间环绕 | 7–13 s | 主视角 → 左 3/4 → 右 3/4，完整收进格架、桌椅 |
| 03 | 桌面细节 | 13–21 s | 抬高越过椅背 → 显示器近景 → 笔记本近景 → 键盘/鼠标/茶杯桌面近景 |
| 04 | 设备互动 | 21–28 s | 笔记本 22.6 s 合盖、25.4 s 开盖，屏幕内容在终端/桌面间切换 |
| 05 | RGB 灯效 | 28–34 s | 单色（青）→ 彩虹 → 呼吸；切换前先压暗再淡入，避免硬闪 |
| 06 | 氛围切换 | 34–40 s | 白天 → 深夜（34 s）→ 专注（36.6 s）→ RGB 氛围（38.8 s） |
| 07 | 终章全景 | 40–45 s | 拉回 3/4 全景；43 s 出现结束标题，45 s 完成后停留约 2 秒并自动恢复初始状态 |

相机使用与场景预设同一套“目标点 + 方位角/仰角/距离/fov”参数。开场从当前相机平滑过渡，之后完全按固定关键帧播放；中景抬高到 2.35–2.45 m，避开椅背并完整显示格架顶部；终章 2.72 m / fov 51° 下工位约占画面高度 84.7%。灯光在每幕切换时按当前实际灯光值向场景基线插值，不会瞬间跳变，也不会叠加多组灯。底部白色字幕按镜头与设备事件更新，实时说明当前功能。暂停会同时冻结时间线、镜头、灯光过渡和演示触发的设备动画；下一章节/重播/退出都作用于同一条时间线。

## 关键尺寸与布局（米）

- 桌面：1050 × 500 × 25 mm，桌面面高 757.5 mm（板中心 745 mm）；两侧木饰面 20 mm（铝框外缘仍与桌沿齐平），内侧可用宽度约 1010 mm；侧板/玻璃深 470 mm，从背板伸到距桌前沿 30 mm 处；背板顶到 1347.5 mm，书架顶面 1372.5 mm；桌面到书架底 590 mm，木侧板高 320 mm、磨砂玻璃高 270 mm。
- 笔记本：按耀世16 Ultra 实物重做为 357 × 264.1 × 20.6 mm 量级，模型底座 357 × 264 × 14.5 mm + 上盖 5.5 mm ≈ 20 mm；底座中心 `(-0.2275, 0.8565, -0.105)`，整体绕 Y 轴向显示器内转 10°、支架斜面 8°。掌托、键盘井、触控板与 C 面齐平（不再凸出 3 mm）；支架前托钩压扁到 8 mm。默认打开 105°、闭合 0°；后部双轴套、真键盘键帽、MECHREVO 铭牌和外盖正读 Logo 均按实机重做，前缘只保留低亮度暖光。
- 键盘：98 键，中心 `(-0.087, 0.7665, 0.1245)`；后移并右移后，前缘距桌沿约 3 mm，右侧距鼠标垫 32 mm，左侧距纸品约 11 mm。底壳按实物改为前低后高楔形：389 × 144 mm，壳前 11 mm、壳后 18 mm，含 2 mm 脚垫后前缘总高约 13 mm、后缘约 20 mm，台面坡度约 2.8°；键帽顶距桌面前排约 24.3 mm、后排约 29.2 mm，旋钮最高点约 31.9 mm；定位板、键床、状态灯和旋钮随坡度同步抬升。
- 键盘 RGB：由**键缝底光 + 键帽染色点光 + 桌面溢光**三层组成。底光贴图在彩虹模式下保持原始渐变、不再乘单色而发灰；`keyboard-rgb-light` 为不投影的短距离点光（强度 0.04–0.10、距离 0.55 m、衰减 1.9，抬到键床上方中央），把颜色带到键帽与腕托；桌面溢光面 0.55 × 0.15 m 收在机身两侧与后侧。三层都收在机身投影内，正面视角不再出现前沿彩色硬光带；关闭模式下三层同时熄灭。
- 显示器：540 × 322 mm（23.8" 16:9，屏幕 527 × 296 mm），面板厚 9 mm（AOC Q24G2 实物量级）、背壳 14 mm；为匹配实物图中“笔记本右端与显示器屏幕左端不错开”的层次，整机后移 70 mm、左移 20 mm，圆盘底座缩小约 16% 避开后方插排。显示器屏幕面 z≈-0.197，与笔记本屏幕面 z≈-0.181 相差约 16 mm。显示器面板向笔记本一侧回望 4°。显示器信号线已按用户要求删除。
- 鼠标垫：340 × 250 mm，**竖放**：长边 340 mm 沿桌面前后（Z）、短边 250 mm 沿左右（X），中心 `(0.330, 0.759, 0.015)`，整体绕 Y 转 -90°；垫面为偏冷中灰布面（`#A8ABAE` + 织物贴图），印有深灰折角带/竖条 + `inphic` 与长句 + 角部点列，四周为浅灰锁边缝线；鼠标为英菲克无线上盖放样壳体，位于垫面中前部，朝向随垫子补偿 +90° 后仍朝向用户；无鼠标线缆。
- 插座：白色 4 位插排约 200 × 50 × 32 mm，中心 `(0.026, 0.7735, -0.135)`，位于显示器左后、笔记本右后的桌面空隙；插有白色 USB 电源和圆头插头，线缆沿设备后方下行，不再穿过显示器背壳。

## 已知限制

- 场景中没有独立台灯，灯光面板只调节现有环境光/主光/桌下补光与屏幕辉光；自动环绕被限制在正面弧内，以免相机穿过单面背墙。
- 设计树是常驻在场景左上角的覆盖层，展开多个节点时会遮住左上部分场景，可用标题栏箭头整体折叠；节点展开状态不写入偏好，刷新后回到全部折叠。
- 格架内部为保持参考中的均匀受光：搁板参与遮挡，下方背板不接收阴影；架顶绿色盒/本子改用接触阴影，不产生实时投影。
- 舞台地板是 2.4 × 2.25 m 的紧凑地台，不是无限地面；极低角度左右 3/4 时画面角落可能看到地台边缘，这是当前舞台的设计边界，默认/正面/俯视构图不受影响。
- 偏好保存在当前浏览器的 `localStorage`，不会跨设备同步；清空站点数据会恢复白天模式与主视角。
- 无头 SwiftShader 下帧率极低（约 1–2 fps），阻尼类动画（显示器旋转、椅子后仰）与相机缓动需要更长等待；交互回归已相应延长等待时间，不降低断言阈值。自动展示在无头环境用 `seek()` 定位，未逐帧录制完整的 45 秒演出。
